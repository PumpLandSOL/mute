# MUTE — private dollars on Robinhood Chain

**Dollars with the sound off.** mUSD is a private, fractional-algorithmic dollar; mute it and the amount and both parties never reach the ledger. $MUTE is the share token.

Dependency-free Node. `npm start` (port 8220). Local dev with faucet: `node _studio/dev.js`.

Features: USDG deposits verified on-chain, Mint / Redeem, Mute / Send, Drops (pay links), Mirror (view keys), Blind Desk (muted stock positions), Bonds + Cryo, the Window (staking), Quiet Yield (40% of fees to muted holders), Erase (buyback & burn), Relays (referrals).

Env: `MUTE_MINT`, `TREASURY`, `ADMIN_KEY`, `DATA_PATH`, `QUIET_CUT`, `HAPPY_*`, `BOND_*`, `FREEZER_*`, `PUNCH_CUT`, `DARK_*`, `MIN_DEPOSIT`.
